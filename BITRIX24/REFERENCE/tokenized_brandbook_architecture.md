# Токенизированная архитектура брендбука

Документ очищен от исходного бренда и превращен в универсальный каркас для последующей адаптации под новую компанию. Структура сохранена постранично: для каждой страницы указаны назначение, токенизированный текст, визуальные плейсхолдеры и комментарии для внедрения.

## Словарь токенов
- **[БРЕНД]** - название новой компании / бренда
- **[КОМПАНИЯ]** - юридическое или коммуникационное название компании
- **[ГРУППА КОМПАНИЙ]** - если бренд представлен группой компаний или холдингом
- **[СФЕРА]** - рынок / отрасль / категория бизнеса
- **[МИССИЯ / КЛЮЧЕВАЯ ИДЕЯ]** - короткая смысловая формула бренда
- **[ЦЕННОСТИ]** - перечень атрибутов и смысловых характеристик бренда
- **[ЗНАК]** - ключевой графический символ бренда
- **[ЛОГОТИП]** - словесное написание / кастомный леттеринг бренда
- **[ФИРМЕННЫЙ БЛОК]** - композиция логотипа, знака и статусной строки
- **[СТАТУСНАЯ СТРОКА]** - подразделение, дескриптор, слоган или адрес сайта
- **[ПАТТЕРН]** - фирменный орнамент / повторяемый модуль
- **[ФИРМЕННЫЙ ЦВЕТ 1/2]** - основные цвета бренда с Pantone/RGB/CMYK/HEX
- **[ШРИФТ 1/2/3]** - набор фирменных шрифтов и их роли
- **[АДРЕС]** - адресный блок компании
- **[ТЕЛЕФОН]** - телефонный номер
- **[EMAIL]** - электронная почта
- **[САЙТ]** - адрес сайта
- **[ФИО]** - имя сотрудника
- **[ДОЛЖНОСТЬ]** - должность сотрудника
- **[УСЛУГА / НАПРАВЛЕНИЕ]** - направление деятельности или продуктовая линия
- **[ОБЪЕКТ / ПРОЕКТ]** - пример проекта / клиента / объекта
- **[ФОТО / ИЛЛЮСТРАЦИЯ]** - изображение, заменяемое новым материалом
