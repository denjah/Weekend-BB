# Дизайн-токены и спецификация интерфейса (UI/UX Tokenization)
## Проект: Анализ и декомпозиция стиля (вдохновлено CreativeCue)

Этот файл содержит подробную токенизацию дизайн-системы, описывающую визуальный язык, типографику, сетки, компоненты и микроинтердейсы. Данная спецификация предназначена для передачи ИИ (LLM) с целью точного воспроизведения аналогичного визуального стиля в новых проектах.

---

## 1. Цветовая палитра (Color Tokens)

Стиль опирается на высокий контраст, минимализм и строгую премиальную эстетику с акцентными деталями, передающими энергию и связь.

### Base Colors (Основа)
* `--color-bg-primary`: `#0D0D0D` (Глубокий черный — основной фон)
* `--color-bg-secondary`: `#171717` (Темно-серый — для карточек и выделенных блоков)
* `--color-bg-tertiary`: `#F2F2F2` (Светло-серый — для инвертированных секций)
* `--color-text-primary`: `#FFFFFF` (Белый — основной текст)
* `--color-text-secondary`: `#A3A3A3` (Серый — описания, второстепенные элементы, нумерация)
* `--color-text-inverse`: `#0D0D0D` (Черный — для текста на светлом фоне)

### Accent Colors (Акценты)
* `--color-accent-primary`: `#FF5E00` (Яркий оранжевый — для кнопок (Book A Call), ховеров и элементов, символизирующих коннективность и динамику)
* `--color-accent-hover`: `#CC4B00` (Приглушенный оранжевый для состояний наведения)
* `--color-border-subtle`: `rgba(255, 255, 255, 0.1)` (Полупрозрачный белый для деликатных разделителей)

## 2. Типографика (Typography Tokens)

Шрифтовая пара строится на использовании современного, техничного и в то же время выразительного гротеска. Крупные заголовки и строгая иерархия.

### Font Families
* `--font-family-heading`: `'PP Neue Montreal', 'Inter', sans-serif` (Геометричный, плотный)
* `--font-family-body`: `'Inter', 'SF Pro Display', sans-serif`
* `--font-family-mono`: `'JetBrains Mono', monospace` (Для нумерации типа `(01)`, `(1.1)`)

### Font Sizes (Scale)
* `--text-xs`: `0.75rem` (12px) - Бейджи, мелкие подписи
* `--text-sm`: `0.875rem` (14px) - Нумерация, теги
* `--text-base`: `1rem` (16px) - Основной текст (Body)
* `--text-md`: `1.125rem` (18px) - Выделенный текст, лиды
* `--text-lg`: `1.5rem` (24px) - Подзаголовки карточек (H4)
* `--text-xl`: `2rem` (32px) - Заголовки секций (H3)
* `--text-2xl`: `3.5rem` (56px) - Крупные заголовки (H2)
* `--text-3xl`: `5rem` (80px) - Главный экран / Hero Headline (H1)

### Font Weights
* `--font-weight-regular`: `400`
* `--font-weight-medium`: `500` (Кнопки, навигация)
* `--font-weight-semibold`: `600` (Заголовки карточек)
* `--font-weight-bold`: `700` (Крупные акценты)

### Line Heights & Tracking
* `--line-height-tight`: `1.1` (Для заголовков H1-H3)
* `--line-height-base`: `1.5` (Для Body)
* `--tracking-tight`: `-0.02em` (Для крупных заголовков)
* `--tracking-widest`: `0.05em` (Для капса и нумерации)

## 3. Отступы и сетка (Spacing & Grid)

Структура макета использует просторные отступы для создания ощущения премиальности и "воздуха".

### Spacing Scale
* `--space-1`: `4px`
* `--space-2`: `8px`
* `--space-3`: `12px`
* `--space-4`: `16px` (Внутренние отступы в кнопках)
* `--space-6`: `24px`
* `--space-8`: `32px` (Отступы внутри карточек Bento-грида)
* `--space-12`: `48px`
* `--space-16`: `64px`
* `--space-24`: `96px` (Отступы между небольшими секциями)
* `--space-32`: `128px` (Глобальные отступы между крупными блоками)

### Grid System
* **Максимальная ширина контейнера:** `1440px`
* **Колонки:** 12 колонок
* **Gaps (Расстояния между колонками):** `24px`
* **Стиль сетки:** Модульный "Bento Box" для сервисов и тарифов. Карточки плотно прилегают или имеют тонкие бордеры-разделители.

## 4. Эффекты и тени (Elevations & Shadows)

Важная часть стиля — использование специфических теней, создающих физическое ощущение элементов (отсылка к "coin-shadow" и "spring-shadow").

* `--shadow-coin`: `0px 4px 0px 0px rgba(255, 94, 0, 1)` (Резкая, плотная тень, создающая эффект объема "монетки", часто в цвете акцента)
* `--shadow-spring`: `0px 8px 24px -4px rgba(0, 0, 0, 0.4)` (Мягкая, широкая тень, используемая при наведении для эффекта пружинящего отрыва от фона)
* `--radius-sm`: `8px` (Внутренние элементы, теги)
* `--radius-md`: `16px` (Карточки услуг, кнопки)
* `--radius-lg`: `24px` (Крупные блоки, секции тарифов)
* `--radius-pill`: `9999px` (Кнопки CTA, бейджи)

## 5. Компоненты (Components Specification)

### 5.1. Кнопки (Buttons)
* **Primary (Book A Call):**
    * Background: `--color-accent-primary`
    * Text Color: `#FFFFFF`
    * Border-radius: `--radius-pill`
    * Padding: `16px 32px`
    * Typography: `--text-base`, `--font-weight-medium`
    * Hover State: Трансформация `translateY(-2px)`, добавление `--shadow-spring`.

### 5.2. Карточки сервисов / Bento Box
* **Структура:** Индикатор номера (например, `(01)` моноширинным шрифтом в левом верхнем углу), Заголовок, Описание.
* **Стилинг:**
    * Background: `--color-bg-secondary`
    * Border: `1px solid --color-border-subtle`
    * Border-radius: `--radius-md`
    * Padding: `--space-8`

### 5.3. Списки и нумерация (Lists & Indexing)
* Стиль списков техничный, похожий на оглавление документации или ТЗ.
* Формат: `(1.1) Creative Strategy`, `(1.2) Identity`.
* Цвет нумерации: `--color-text-secondary`.
* Шрифт нумерации: `--font-family-mono`.

### 5.4. Блок отзывов (Testimonials)
* **Элементы:** Текст отзыва (крупный, `--text-md` или `--text-lg`, italic), Аватар пользователя, Имя, Должность, Логотип компании.
* **Особенность:** Использование бекграундов под конкретного клиента (`underlining-background`, `botb-background`), возможно легкое тонирование карточки в фирменный цвет клиента.

---

## 6. Анимации и микроинтерфейсы (Animations)

* `--transition-fast`: `150ms ease-in-out` (Ховеры на ссылках, смена цвета)
* `--transition-spring`: `400ms cubic-bezier(0.175, 0.885, 0.32, 1.275)` (Пружинящая анимация для карточек и кнопок при наведении, связанная с эффектом `spring-shadow`)
* **Скролл-эффекты:** Плавное появление элементов (Fade in + Transform translateY от `20px` до `0`). Текст заголовков может появляться построчно (Staggered text reveal).
* **Marquee (Бегущая строка):** Используется для бесконечного списка логотипов или ключевых слов (например, "Trusted by world's most exciting brands").

---

## 7. Инструкция для ИИ (AI Prompt Guidelines)

При генерации компонентов на основе данного tokenfile.md, ИИ должен:
1.  Строго соблюдать иерархию заголовков и использовать плотный трекинг (`tracking-tight`) для больших текстов.
2.  Применять моноширинный шрифт для любых числовых индексов `(01)`, `(02)` для сохранения технической, инженерной эстетики.
3.  Избегать лишних декоративных элементов: визуальный вес должен формироваться за счет типографики, контраста фона (`#0D0D0D`) и точечных оранжевых акцентов (`#FF5E00`).
4.  Использовать эффект `coin-shadow` для выделения интерактивных элементов на плоскости.
