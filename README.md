# Weekend Billiard Corporate Brandbook

Современный, производительный и интерактивный корпоративный брендбук, переписанный на стеке **React 19 + Vite + TypeScript**.

## Особенности
- **3 Уникальные Темы Дизайна**: Переключайтесь между Ethereal Glass, Editorial Luxury и Soft Structuralism. Дизайн-система основана на CSS-переменных, которые мгновенно меняются без перезагрузки страницы.
- **GSAP Анимации**: Интерактивные фоновые частицы (Canvas-based), staggered появление карточек, Magnetic Buttons (магнитные кнопки) и плавные Scroll Reveal эффекты.
- **Модульная Архитектура**: Каждая глава брендбука — это отдельная страница (lazy loading). Компоненты UI (Card, Badge, ProgressBar) переиспользуются по всему проекту.
- **Legacy Данные**: Старый архив страниц (logobook) бережно перенесен в `logobook.json` и рендерится с помощью специального компонента `LogobookViewer.tsx`.
- **Zustand State**: Глобальное управление темами и состоянием интерфейса.
- **Vibe-coding Ready**: Минималистичный и чистый код, строгая типизация TypeScript.

## Стек технологий
- **Core**: React 19, TypeScript, Vite
- **Routing**: React Router v7
- **State**: Zustand
- **Animations**: GSAP (`@gsap/react`), Canvas Particles
- **Styling**: Tailwind CSS, Vanilla CSS (`tokens.css`, `global.css`)

## Запуск проекта

Убедитесь, что у вас установлен Node.js (v18+).

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера (с HMR)
npm run dev

# Сборка для production
npm run build
```

## Структура папок
- `src/components/` — UI-компоненты, секции, эффекты (GSAP).
- `src/styles/` — Дизайн-система, темы и токены.
- `src/store/` — Zustand store (App + Brand данные).
- `src/types/` — TS-интерфейсы.
- `src/data/` — JSON архивы.
- `src/services/` — Mock API.
- `v1-vanilla/` — Старая версия проекта (архив).

## Деплой на Beget (Production)

Для администратора сервера: проект полностью готов к загрузке на хостинг Beget с поддержкой PHP (версия >= 7.4).

### Структура файлов
После выполнения команды `npm run build` все необходимые файлы для деплоя собираются в папке `dist/`. 

```text
public_html/                    ← корневая директория сайта на Beget
├── .htaccess                   ← настроен для SPA-роутинга и API
├── index.html                  ← точка входа React-приложения
├── assets/                     ← JS/CSS бандлы
├── api/                        ← PHP-бэкенд для загрузки файлов и комментариев
│   ├── comments.php
│   ├── upload.php
│   └── data/                   ← БД в формате JSON (создается автоматически)
└── uploads/                    ← папка для загруженных файлов (создается автоматически)
```

### Пошаговая инструкция по деплою
1. На сервере Beget очистите папку `public_html/`.
2. Загрузите туда **Всё содержимое папки `dist/`** из этого репозитория. (Обязательно скопируйте скрытый файл `.htaccess`).
3. Убедитесь, что внутри `public_html/` лежит папка `api/` с PHP-файлами.
4. Выдайте папке `api/` права **755**, а файлам внутри неё — **644**.
5. На этом всё. При первой загрузке файла или комментария папки `uploads/` и `api/data/` будут созданы автоматически.

### Решение проблем (Troubleshooting)
- Если возникает **Ошибка 404 при обновлении страницы**: убедитесь, что скрытый файл `.htaccess` из папки `dist` скопирован на сервер.
- Если **Файлы не загружаются**: убедитесь, что у PHP есть права на запись в папку `public_html/` (папки `uploads/` и `api/data/` должны создаваться скриптом, если этого не происходит — создайте их вручную и выдайте права `777`).
- Если **Не работают комментарии (CORS)**: проверьте, что фронтенд и API лежат на одном и том же домене. Заголовки `Access-Control-Allow-Origin: *` уже встроены в `comments.php` и `upload.php`.
