# Деплой брендбука на Beget

## Что было сделано

### Фронтенд (React/Vite)
- Все 7 секций (`BrandIdentity`, `VisualSystem`, `LogoUsage`, `Marketing`, `Corporate`, `Digital`, `Physical`, `Resources`) переведены на живое API
- Каждый подраздел получил уникальный `sectionId` — файлы и комменты привязаны к своим окнам
- Создан универсальный компонент `SectionContent` — автоматически загружает файлы и комменты для своего окна с сервера
- При загрузке файла/добавлении комментария — глобальная статистика на Dashboard обновляется в реальном времени
- `ThemeSwitcher` перенесён из сайдбара в хедер

### Бэкенд (PHP)
- `api/comments.php` — GET (фильтр по section_id), POST (добавление), CORS, поле `author`
- `api/upload.php` — GET (список файлов по section_id), POST (загрузка файла), CORS, `__DIR__` пути
- Данные хранятся в JSON-файлах (`api/data/comments.json`, `api/data/uploads.json`)
- Загруженные файлы хранятся в `uploads/{sectionId}/`

### Найденные и исправленные баги
1. **Несовпадение полей**: PHP сохранял `user`, фронт ожидал `author` — исправлено
2. **POST-запрос комментов**: фронт слал `author`, PHP искал `user_name` — исправлено
3. **Относительные пути PHP**: использовались `'data/...'` вместо `__DIR__` — исправлено (на Beget cwd может не совпадать с папкой скрипта)
4. **CORS-заголовки**: отсутствовали — добавлены `Access-Control-Allow-Origin: *`
5. **URL файлов**: PHP теперь отдаёт готовый `/uploads/...` URL, фронт не парсит `path`

## Инструкция по деплою на Beget

### Структура на сервере

```
public_html/                    ← корень сайта на Beget
├── .htaccess                   ← SPA-роутинг + API passthrough
├── index.html                  ← React SPA
├── assets/                     ← JS/CSS бандлы
├── api/                        ← PHP бэкенд
│   ├── comments.php
│   ├── upload.php
│   └── data/                   ← автосоздается, хранит JSON
│       ├── comments.json
│       └── uploads.json
└── uploads/                    ← автосоздается, хранит файлы
    ├── mission-vision/
    ├── brand-values/
    └── ...
```

### Шаги

1. **Залить содержимое папки `dist/`** в корень сайта на Beget (`public_html/`)
2. **Проверить права**:
   - Папка `api/` — 755
   - PHP-файлы — 644
   - Папки `api/data/` и `uploads/` создадутся автоматически (если не создадутся — создать вручную с правами 755)
3. **Проверить версию PHP** на Beget — должна быть ≥ 7.4
4. **Готово** — открыть сайт в браузере

### Тестирование после деплоя

1. Открыть любой раздел (например, "Brand Identity")
2. Загрузить файл через drag&drop или кнопку — должен появиться в списке
3. Написать комментарий — должен появиться в ленте
4. Вернуться на главную — счётчики "Файлов" и "Комментов" должны обновиться
5. Обновить страницу — файлы и комменты должны остаться на месте

> [!IMPORTANT]
> Папка `uploads/` на Beget будет расти по мере загрузки файлов. На стандартном тарифе Beget обычно 10-50 ГБ дискового пространства — для брендбука хватит с запасом.
